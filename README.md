## Cómo usar

1. Abre `index.html` en un navegador moderno (o sirve la carpeta con un servidor local).
2. Los tres juegos se abren desde la sección **Proyectos** o directamente:
   - `games/cyber-runner/cyber-runner.html`
   - `games/space-invaders-remix/space-invaders.html`
   - `games/neon-puzzle/neon-puzzle.html`

### Servidor local (recomendado)

```bash
npx serve .
# o
python -m http.server 8080
```

## EmailJS (formulario de contacto)

1. Crea una cuenta en [EmailJS](https://www.emailjs.com/).
2. Crea un Service y un Template.
3. En `js/contact.js` reemplaza:
   - `TU_PUBLIC_KEY`
   - `TU_SERVICE_ID`
   - `TU_TEMPLATE_ID`

Sin configurar, el formulario funciona en **modo demo** (simula envío exitoso).
